About FindIt

A simple board that helps people get lost things back.

Why FindIt exists

Phones, wallets, keys and documents go missing every day on buses, in markets and at colleges. Someone usually finds them, but the owner never hears about it. FindIt gives both sides one place to post and search.

How it works

  • Lost something? Post a report with the item, the place and the date.
  • Found something? Post what you found and where you left it.
  • Search and filter by name, place or category.
  • Contact the other person from the details popup, then mark the item as returned.

Stay safe

  • Never post ID numbers, card numbers or passwords in a report.
  • Ask the person to describe a detail only the owner would know before you hand an item over.
  • Meet in a public place.
This is a demo project. It is built with HTML, CSS and JavaScript only. Reports are saved in your own browser, so other visitors cannot see them.
